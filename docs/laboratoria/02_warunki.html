Laboratorium 2

Operacje warunkowe

Wprowadzenie do programowania · C++ · instrukcja laboratoryjna

Cel ćwiczenia: Zapisanie reguł wyboru oraz sprawdzenie danych przed wykonaniem działania.

Środowisko: Visual Studio Community, projekt Console App, standard C++17.

Wejściówka

4 pytania z poprzedniego laboratorium: przewidywanie wyjścia programu, reszta z dzielenia, dzielenie całkowite i uzupełnienie kodu. Każde jest warte 1 punkt. Dodatkowo napisz krótki program z materiału laboratorium 1 w zadaniu otwartym pod pytaniami. Pracuj samodzielnie. Po potwierdzeniu zapisu pojawi się wynik testu wyboru (0–4); kod sprawdzi prowadzący osobno, bez automatycznej oceny.

Przyjmij, że każdy fragment znajduje się wewnątrz poprawnie zdefiniowanej funkcji main i dołączono nagłówek <iostream>. Pytanie o uzupełnienie zawiera celowo oznaczoną lukę. W pozostałych pytaniach analizuj kod dokładnie w podanej postaci.

1. Wykonanie instrukcji pod warunkiem — if

Instrukcja if pozwala wykonać blok instrukcji tylko wtedy, gdy podany warunek jest prawdziwy. Jeżeli warunek jest fałszywy, program pomija blok i wykonuje dalsze instrukcje. Wynik porównania ma typ bool: wartość true oznacza prawdę, a false fałsz.

Ogólna postać:

if (condition) {
    // Instructions executed when condition is true.
}
// Execution continues here in either case.

condition to sprawdzany warunek. Zapisujemy go w nawiasach okrągłych, a zależne od niego instrukcje umieszczamy w nawiasach klamrowych. Nie stawiamy średnika bezpośrednio po if (condition) — taki średnik byłby pustą instrukcją, a następujący po nim blok nie zależałby od warunku.

Do budowania warunków służą operatory porównania:

Operator Znaczenie Przykład
== Równe count == 10
!= Różne count != 10
<, > Mniejsze, większe temperature > 50.0
<=, >= Mniejsze lub równe, większe lub równe temperature >= 50.0

= służy do przypisania wartości, a == do porównania. Nie są zamienne: count = 10 zmienia zawartość zmiennej, natomiast count == 10 sprawdza jej wartość.

Przykład nowej konstrukcji: dla istniejącej zmiennej speed poniższy fragment wypisze ostrzeżenie tylko przy wartości większej od 80. Komunikat końcowy pojawi się niezależnie od wyniku porównania.

if (speed > 80.0) {
    std::cout << "Speed limit exceeded\n";
}
std::cout << "Check completed\n";

Zadanie 1. Ostrzeżenie o temperaturze

Napisz od początku program, który wczytuje temperaturę typu double. Gdy temperatura przekracza 50°C, wypisz Temperature too high. Na końcu, niezależnie od temperatury, wypisz Measurement completed.

Sprawdź: 49, 50, 51. Dla 49 i 50 ma pojawić się tylko komunikat końcowy, a dla 51 oba komunikaty.

Wyjaśnij: dlaczego komunikat końcowy znajduje się poza blokiem if? Co zmieni zastąpienie > przez >=?

2. Wybór jednej z dwóch możliwości — if/else

Jeśli program ma wykonać jedną czynność po spełnieniu warunku, a inną w przeciwnym przypadku, używamy if/else. Wykona się dokładnie jeden z dwóch bloków. else nie ma własnego warunku — obejmuje przypadki, w których warunek przy if jest fałszywy.

Ogólna postać:

if (condition) {
    // Instructions executed when condition is true.
} else {
    // Instructions executed when condition is false.
}

Przykład nowej konstrukcji: zakładamy, że zmienna age zawiera już wczytany wiek.

if (age >= 18) {
    std::cout << "Adult\n";
} else {
    std::cout << "Under 18\n";
}

W zadaniu przyda się znany z poprzedniego laboratorium operator %, czyli reszta z dzielenia całkowitego. Liczba całkowita jest parzysta, gdy reszta z dzielenia przez 2 wynosi zero. Dotyczy to również zera i parzystych liczb ujemnych.

Zadanie 2. Parzystość liczby

Wczytaj liczbę typu int. Użyj if/else, aby wypisać dokładnie jeden komunikat: Even albo Odd.

Sprawdź: -4, -3, 0, 7, 8. Oczekiwane wyniki to kolejno Even, Odd, Even, Odd, Even.

Wyjaśnij: dlaczego sprawdzenie reszty różnej od zera rozpoznaje również ujemne liczby nieparzyste? Czy warunek reszty równej 1 obejmowałby wszystkie takie liczby?

3. Więcej niż dwie możliwości — else if

Łańcuch if / else if / else służy do wyboru spośród kilku możliwości. Program sprawdza warunki od góry. Po napotkaniu pierwszego prawdziwego warunku wykonuje jego blok i pomija pozostałe gałęzie tego łańcucha. Jeśli żaden warunek nie jest prawdziwy, wykonuje blok else, o ile został zapisany.

Ogólna postać:

if (first_condition) {
    // Instructions for the first case.
} else if (second_condition) {
    // Instructions for the second case.
} else {
    // Instructions for all remaining cases.
}

Przykład nowej konstrukcji: dla istniejącej zmiennej temperature wybieramy jeden opis.

if (temperature < 0.0) {
    std::cout << "Below freezing\n";
} else if (temperature < 20.0) {
    std::cout << "Cool\n";
} else {
    std::cout << "Warm\n";
}

Drugi warunek jest sprawdzany dopiero po odrzuceniu pierwszego. Dlatego druga gałąź obejmuje temperatury od 0 włącznie do 20 wyłącznie, mimo że zapisano w niej tylko górną granicę. Zmiana kolejności warunków może zmienić wynik. Kilka oddzielnych instrukcji if działa inaczej: każda jest sprawdzana niezależnie i może wykonać własny blok.

Zadanie 3. Znak liczby

Wczytaj liczbę typu int. Za pomocą jednego łańcucha if / else if / else wypisz dokładnie jeden komunikat: Positive, Negative albo Zero. Nie dodawaj osobnego porównania w ostatniej gałęzi, jeśli wcześniejsze warunki wykluczają już oba pozostałe przypadki.

Sprawdź: -5, 0, 5.

Wyjaśnij: jakie informacje o liczbie masz już w ostatniej gałęzi? Prześledź w debuggerze, które porównania zostaną wykonane dla każdego wejścia. Ustaw punkt zatrzymania przed pierwszym if i wykonuj kolejne kroki klawiszem F10.

4. Jednoczesne spełnienie warunków — operator &&

Operator logiczny && oznacza „i”. Wyrażenie złożone z dwóch warunków jest prawdziwe tylko wtedy, gdy oba warunki są prawdziwe. Pozwala to np. sprawdzić dolną i górną granicę przedziału.

Ogólna postać:

first_condition && second_condition

Przykład nowej konstrukcji: zmienna pressure zawiera już wynik pomiaru.

if (pressure >= 950.0 && pressure <= 1050.0) {
    std::cout << "Pressure within range\n";
}

Każde porównanie zapisujemy w całości. Matematyczny zapis 950 <= pressure <= 1050 nie sprawdza przedziału w C++: pierwsze porównanie dałoby wartość logiczną, która następnie byłaby porównywana z 1050. Operator && sprawdza prawy warunek tylko wtedy, gdy lewy jest prawdziwy; jest to obliczanie ze skracaniem.

Zadanie 4. Dopuszczalny zakres pomiaru

Wczytaj temperaturę typu double. Poprawny zakres wynosi od -20°C do 50°C włącznie. Użyj && i if/else, aby wypisać Valid temperature albo Invalid temperature.

Sprawdź: -21, -20, 0, 50, 51. Obie granice muszą zostać zaakceptowane.

Wyjaśnij: dlaczego potrzebne są dwa pełne porównania? Co stanie się dla temperatury 0, jeśli w swoim warunku zastąpisz && przez ||?

5. Wystarczy jeden spełniony warunek — operator ||

Operator logiczny || oznacza „lub” w sensie niewykluczającym: wynik jest prawdziwy, gdy co najmniej jeden z warunków jest prawdziwy. Do wykrycia wartości spoza przedziału wystarczy przekroczenie jednej z jego granic.

Ogólna postać:

first_condition || second_condition

Przykład nowej konstrukcji: zmienna humidity zawiera już wczytaną wilgotność procentową.

if (humidity < 0.0 || humidity > 100.0) {
    std::cout << "Invalid humidity\n";
}

Prawy warunek jest sprawdzany tylko wtedy, gdy lewy jest fałszywy. W wyrażeniach łączących && i || stosuj nawiasy, aby wyraźnie wskazać grupowanie reguł. Operator && ma wyższy priorytet niż ||.

Zadanie 5. Kategorie naładowania baterii

Wczytaj całkowity procent naładowania baterii. Najpierw za pomocą || odrzuć wartości spoza zakresu 0–100 komunikatem Invalid charge. Dla poprawnych danych wypisz jedną kategorię: poniżej 30 — Recharge, od 30 do 79 — Ready, od 80 do 100 — Full readiness. Zastosuj jeden łańcuch warunków, zaczynając od kontroli błędu.

Sprawdź: -1, 0, 29, 30, 79, 80, 100, 101. Dla -1 i 101 ma pojawić się wyłącznie komunikat o błędzie.

Wyjaśnij: dlaczego kontrola zakresu musi poprzedzać klasyfikację w tym układzie? Co byłoby wynikiem dla 101, gdyby program sprawdzał tylko progi 30 i 80? Następnie zmień próg pełnej gotowości na 90 i sprawdź 89 oraz 90.

6. Zaprzeczenie i zmienne logiczne — operator !

Zmienna typu bool przechowuje wartość true albo false. Może opisywać stan, np. wykonanie przeglądu. Można użyć jej bezpośrednio jako warunku, bez dopisywania == true. Operator ! odwraca wartość logiczną: z prawdy tworzy fałsz, a z fałszu prawdę.

Ogólna postać:

!condition

Przykład nowej konstrukcji: zakładamy, że istnieje zmienna bool connected.

if (!connected) {
    std::cout << "No connection\n";
} else {
    std::cout << "Connected\n";
}

Dla wyrażenia złożonego zaprzeczenie zapisujemy z nawiasami, np. !(first_condition && second_condition). Taki zapis sprawdza, czy nie są spełnione oba wymagania jednocześnie; nie jest równoważny !first_condition && !second_condition.

Zadanie 6. Zgoda na wydanie urządzenia

Wczytaj procent baterii jako int oraz stan przeglądu checked jako bool. Na potrzeby tego zadania załóż poprawny odczyt: bateria jest w zakresie 0–100, a przegląd jest podany jako 0 albo 1. Urządzenie można wydać tylko wtedy, gdy bateria ma co najmniej 30% i przegląd wykonano.

Zapisz wynik tej reguły w zmiennej bool canIssue. Użyj !canIssue jako warunku odmowy i wypisz Cannot issue albo Can issue.

Sprawdź: (29, 1), (30, 0), (30, 1), (100, 1). Tylko dwie ostatnie pary pozwalają wydać urządzenie.

Wyjaśnij: czym różni się zaprzeczenie całej reguły od jednoczesnego wymagania niskiej baterii i braku przeglądu? Czy wystarczy niespełnienie jednego wymagania, aby odmówić wydania?

7. Wybór wartości — operator warunkowy ?:

Instrukcja if/else wybiera instrukcje do wykonania. Operator warunkowy ?: tworzy natomiast wyrażenie: zależnie od warunku wybiera jedną z dwóch wartości. Wynik można np. przypisać do zmiennej albo wykorzystać w obliczeniu.

Ogólna postać:

condition ? value_if_true : value_if_false

Najpierw obliczany jest condition. Jeżeli jest prawdziwy, obliczane jest wyrażenie po ?; jeżeli fałszywy — wyrażenie po :. Obliczana jest tylko wybrana gałąź. W tych ćwiczeniach stosuj w obu gałęziach wartości tego samego typu, aby nie wprowadzać dodatkowych konwersji.

Przykład nowej konstrukcji: istniejąca zmienna express ma typ bool. W zależności od jej wartości wybieramy koszt dostawy.

double deliveryCost = express ? 15.0 : 8.0;

Dla express == true zmienna otrzyma 15.0, a dla false otrzyma 8.0. Średnik kończy deklarację zmiennej; nie jest częścią samego operatora. ?: stosuj do prostego wyboru wartości. Nie zagnieżdżaj go w tym zadaniu.

Zadanie 7. Większa z dwóch wartości

Wczytaj dwie liczby typu double. Za pomocą operatora ?: wybierz większą wartość i zapisz ją w nowej zmiennej typu double. Następnie wypisz tę zmienną. Nie zastępuj operatora instrukcją if/else ani gotową funkcją wybierającą maksimum.

Sprawdź: (2.5, 7.0), (8.0, -1.0), (-4.0, -2.0), (3.0, 3.0). Oczekiwane wartości to 7, 8, -2 i 3.

Wyjaśnij: która gałąź zostanie wybrana dla dwóch równych liczb przy porównaniu >? Czy zmiana tego porównania na >= zmieni wypisaną wartość? Zapisz odpowiednik swojego wyboru za pomocą if/else, aby porównać obie konstrukcje.

8. Sprawdzenie odczytu i wcześniejsze zakończenie programu

Dotąd w zadaniach zakładaliśmy poprawne wczytanie danych. Odczyt std::cin >> value może się jednak nie udać, np. po wpisaniu tekstu zamiast liczby. Stan strumienia można sprawdzić w warunku. Operator ! pozwala wejść do bloku obsługi nieudanego odczytu.

Ogólna postać dla jednego odczytu:

if (!(std::cin >> value)) {
    // Handle the failed read.
    return 1;
}

Zmienna value musi zostać wcześniej zadeklarowana. Nawiasy w !(std::cin >> value) obejmują cały odczyt. return 1; użyte wewnątrz main kończy program z niezerowym kodem, którym sygnalizujemy błąd. Instrukcje znajdujące się dalej nie zostaną wtedy wykonane.

Przykład nowej konstrukcji: dla istniejących zmiennych liczbowych length i width można sprawdzić dwa odczyty razem.

if (!(std::cin >> length >> width)) {
    std::cout << "Invalid input\n";
    return 1;
}

Nieudany odczyt i niedopuszczalna wartość to różne sytuacje. Zero może zostać poprawnie wczytane, a mimo to nie nadawać się na dzielnik. Sprawdzenie stanu strumienia nie gwarantuje też, że wykorzystano cały wpisany tekst: np. odczyt liczby z 12abc może wczytać początkowe 12 i pozostawić resztę w strumieniu. W tym laboratorium sprawdzamy powodzenie wymaganych odczytów, bez analizy całego wiersza.

Zadanie 8. Dzielenie z kontrolą danych

Wczytaj dwie liczby typu double. Jeżeli odczyt się nie powiedzie, wypisz Invalid input i zakończ program przed obliczeniami. Po poprawnym odczycie sprawdź dzielnik: dla zera wypisz Division by zero i również zakończ program. Dopiero po obu sprawdzeniach oblicz i wypisz iloraz.

Sprawdź: 8 2, 8 0, 0 2, abc 2, 8 abc. Oczekiwane wyniki to kolejno 4, komunikat o zerowym dzielniku, 0 oraz dwa komunikaty o błędzie odczytu. Dla każdej błędnej próby program ma wypisać jeden odpowiedni komunikat i nie wykonywać dzielenia.

Wyjaśnij: dlaczego poprawności odczytu nie zastępuje samo sprawdzenie dzielnika? Pokaż w debuggerze, że po wykonaniu return 1; program nie dochodzi do obliczania ilorazu.

9. Wybór według konkretnej wartości — switch

switch służy do wyboru działania na podstawie wartości całkowitej, znaku lub wartości typu wyliczeniowego. Etykieta case wskazuje konkretną stałą, np. 1 albo 'a'. default obsługuje brak dopasowania. switch nie służy do bezpośredniego porównywania przedziałów ani wartości typu double.

Ogólna postać:

switch (selector) {
case first_value:
    // Instructions for the first value.
    break;
case second_value:
    // Instructions for the second value.
    break;
default:
    // Instructions when no case matches.
    break;
}

selector jest sprawdzaną wartością. Stałe przy case muszą być znane w czasie kompilacji i nie mogą się powtarzać. break kończy wykonanie switch; bez niego program może wykonywać także instrukcje pod kolejnymi etykietami, bez ponownego sprawdzania dopasowania.

Przykład nowej konstrukcji: istniejąca zmienna option ma typ char.

switch (option) {
case 'a':
    std::cout << "Add\n";
    break;
case 'r':
    std::cout << "Report\n";
    break;
default:
    std::cout << "Unknown option\n";
    break;
}

Zadanie 9. Menu komunikatów

Wczytaj wybór użytkownika jako int. Użyj switch: dla 1 wypisz Start measurement, dla 2 — Show last result, dla 3 — Finish. Dla każdej innej liczby wypisz Unknown option. Program ma obsłużyć jeden wybór i zakończyć się; nie dodawaj pętli. Załóż poprawny odczyt liczby całkowitej.

Sprawdź: 1, 2, 3, 0, 4. Przy każdej próbie ma pojawić się dokładnie jeden komunikat.

Wyjaśnij: do czego służy default? Tymczasowo usuń break po pierwszym przypadku i uruchom program dla 1. Zapisz, które komunikaty się pojawiły i dlaczego, a następnie przywróć break.

10. Połączenie wyboru operacji i kontroli danych

W jednym programie można łączyć poznane konstrukcje: sprawdzić odczyt, wybrać operację przez switch i wewnątrz wybranego przypadku użyć if. Każde sprawdzenie powinno poprzedzać działanie, które wymaga poprawnych danych. Szczególne wymaganie jednej operacji, np. niezerowy dzielnik, sprawdzamy w jej gałęzi.

Ogólna forma zagnieżdżenia — zakładamy, że operation jest wcześniej wczytanym znakiem, a condition opisuje wymaganie danej operacji:

switch (operation) {
case 'x': {
    if (condition) {
        // Perform the operation when its requirement is met.
    } else {
        // Report why this operation cannot be performed.
    }
    break;
}
default:
    // Handle an unknown operation.
    break;
}

Klamry po case 'x': tworzą blok. Są przydatne, gdy w danym przypadku deklarujesz zmienne lokalne: oddzielają je od pozostałych przypadków.

Przykład nowej kombinacji: wewnątrz switch taki przypadek mógłby obsłużyć wybór raportu. Zmienna hasData ma typ bool.

case 'r': {
    if (hasData) {
        std::cout << "Report available\n";
    } else {
        std::cout << "No data\n";
    }
    break;
}

Ten fragment jest częścią switch, a nie samodzielną instrukcją do umieszczenia bezpośrednio w main.

Zadanie 10. Kalkulator z wyborem działania

Napisz samodzielnie program wczytujący dane w postaci: liczba, znak działania, liczba, np. 8 / 2. Liczby mają typ double, a znak działania typ char.

Sprawdź powodzenie całego odczytu. W razie błędu wypisz Invalid input i zakończ program. Użyj switch do obsługi +, -, *, /. W przypadku dzielenia sprawdź, czy dzielnik nie jest zerem. Dla zerowego dzielnika wypisz Division by zero, a dla nieznanego operatora Unknown operation. Wynik poprawnego działania wypisz z dwoma miejscami po przecinku. Program wykonuje jedno działanie, bez pętli.

Sprawdź:

Wejście Oczekiwane wyjście
8 / 2 4.00
8 / 0 Division by zero
3 + 4 7.00
3 - 5 -2.00
2.5 * 4 10.00
3 ? 4 Unknown operation
abc + 2 Invalid input
8 / abc Invalid input

Wyjaśnij: dlaczego kontrola zerowego dzielnika dotyczy tylko /, a nie np. mnożenia przez zero? Gdzie w Twoim programie kończy się obsługa nieznanego operatora i dlaczego nie powinna wypisywać wyniku obliczeń?

Dokumentacja i sprawdzenie pracy

Każde zadanie napisz jako kompletny program w osobnym projekcie. Pokazane fragmenty objaśniają wyłącznie nową konstrukcję: samodzielnie dobierz nagłówki, napisz main, zadeklaruj zmienne i dodaj wejście oraz wyjście. Stosuj angielskie nazwy zmiennych i komunikaty. Jeżeli zadanie nie wymaga kontroli odczytu ani nie stanowi inaczej, zakładaj dane zgodne z poleceniem.

  • Zachowaj źródła .cpp oznaczone numerem zadania.
  • Przed każdą próbą zapisz przewidywany wynik, a następnie porównaj go z wynikiem programu.
  • Wykonaj wskazane próby, zwłaszcza te na granicy przedziału.
  • Do każdego zadania przygotuj odpowiedź na pytanie „Wyjaśnij”.
  • Przygotuj się do samodzielnego omówienia wybranego fragmentu kodu.

Sposób przekazania plików ustala prowadzący. Nie trzeba przekazywać katalogów .vs i Debug ani plików .exe.

Przygotowanie do następnej wejściówki

Powtórz

  • Porównania i różnicę między = a ==.
  • Wybór gałęzi if/else, kolejność else if oraz wartości graniczne.
  • Operatory &&, ||, ! i znaczenie nawiasów.
  • Wybór wartości przez condition ? value_if_true : value_if_false.
  • Sprawdzanie odczytu, wcześniejsze zakończenie i kontrolę dzielenia przez zero.
  • switch, case, break, default oraz zagnieżdżenie if w switch.

Przygotuj się do laboratorium 3

Kolejne zajęcia wprowadzą pętle for, while, do…while oraz indeksowanie tablic. Pętla powtarza blok instrukcji. W poniższym fragmencie zmienna sterująca zaczyna od 1; warunek jest sprawdzany przed każdym wykonaniem bloku, a ++i zwiększa wartość po jego wykonaniu.

for (int i = 1; i <= 4; ++i) {
    std::cout << i << '\n';
}

Minimalne przygotowanie: wskaż kolejno wypisywane wartości i liczbę powtórzeń. W tym przykładzie wypisane zostaną 1, 2, 3, 4, więc blok wykona się cztery razy. Nie trzeba jeszcze samodzielnie obliczać średniej z tablicy.

Następna wejściówka: 3 pytania powtórkowe i 1 podstawowe pytanie z zapowiedzianego nowego tematu, po 1 punkcie.
